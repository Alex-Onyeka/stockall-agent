# Stockall Agent Platform

The Stockall Agent Platform is a unified operational system built for all categories of agents within the Stockall ecosystem — including referral agents, marketing teams, delivery personnel, onboarding staff, support agents, and other field or administrative operators.

This platform gives each agent the tools required to efficiently perform their duties, track tasks, manage activities, and stay connected with the central Stockall backend.

## 🚀 Features

- Role-based access for different agent categories
- Authentication & secure login
- Task management tools
- Referral activity tracking
- Delivery and field operations tools
- Real-time updates from the Stockall system
- Lightweight, mobile-friendly interface for field agents
- Integration with Stockall's main backend

## 🛠 Tech Stack

- Flutter (Mobile + Web)
- Supabase (Backend, Auth, Database)
- Vercel (Web deployment)
- Dart (Core logic)
